# 🧠 MindTrace
### AI-Powered Cognitive Assessment and Growth Agent

MindTrace is an AI-powered cognitive assessment platform designed to help users understand their cognitive performance, identify strengths and weaknesses, and improve their reasoning skills through personalized AI coaching.

## ✨ Features

- Six-dimensional cognitive assessment.
- 12, 24, or 36-question assessment modes.
- Adaptive question difficulty.
- Response-time tracking.
- Cognitive performance radar chart.
- AI-powered personalized coaching using Google Gemini.
- User accounts and assessment history.
- Brain Twin progress dashboard.
- Daily cognitive games.

## 🧩 Cognitive Dimensions

- Logic & Patterns
- Numerical Reasoning
- Spatial Reasoning
- Working Memory
- Processing Speed
- Verbal Reasoning

## 🛠️ Technology Stack

- Python 3.12
- Streamlit
- Google Gemini API
- Plotly
- SQLite

## 🚀 Installation

Clone the repository:

    git clone https://github.com/ayhem-76/MindTrace.git

Navigate into the project:

    cd MindTrace

Create a virtual environment:

    python -m venv .venv

Activate it on Windows:

    .venv\Scripts\activate

Install dependencies:

    pip install -r requirements.txt

Configure your Gemini API key in:

    .streamlit/secrets.toml

Run the application:

    streamlit run app.py

## 🔐 Privacy and Security

API credentials and local database files are excluded from version control.

## ⚠️ Limitations

MindTrace is an experimental cognitive assessment and training prototype. Its Cognitive Index is not a standardized IQ score, medical diagnosis, or clinical assessment.
